# Review records

This directory keeps point-in-time project reviews and handoffs. They are
evidence and provenance, **not** a backlog:

- The only actionable backlog is [`../modernization-plan.md`](../modernization-plan.md).
- Accepted review findings are merged into that plan (see
  [section 3.10](../modernization-plan.md#310-post-050-review-follow-up-2026-11-05)).
- Do not add TODO checkboxes here. A finding that is still open belongs in the
  plan; a review document that is fully triaged stays as a frozen snapshot.
